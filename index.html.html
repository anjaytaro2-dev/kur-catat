Tempel kunci API Gemini Anda. Kunci disimpan hanya di browser perangkat ini dan dikirim langsung ke Google, tidak ke server lain.

Buat kunci gratis di aistudio.google.com (menu Get API key). Tier gratis punya batas pemakaian harian. Tanpa kunci, aplikasi tetap mencatat dengan pembaca sederhana.
